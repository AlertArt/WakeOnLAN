## 可点击的操作路径说明

1. 打开 `http://<主机>:8080/` → 未登录自动停在登录页。
2. 输入口令 → 登录 → 进入设备列表页。
3. 点「添加设备」→ 弹层中填名称、MAC、广播地址（端口默认 9）、选校验方式（不校验 / Ping / TCP）→ 保存。
4. 卡片上点「唤醒」→ 按钮依次显示"发送中…"、"校验中…"（每 5 秒自动刷新结果）→ 变为「已上线 / 超时未响应 / 校验失败」。
5. 未配置校验方式的设备：点「唤醒」后提示"唤醒包已发送，无法自动确认是否开机"，不进入轮询。
6. 「编辑」「删除」都在卡片上；删除需二次确认。
7. 右上「退出」吊销当前令牌并回到登录页；令牌过期时任意操作会自动带回登录页并说明原因。

## 遗留与风险

1. **令牌存 `localStorage`，对 XSS 敏感。** 前端全部用 `textContent` 构造 DOM、不拼 `innerHTML`，当前无注入面；但今后任何人往页面里加第三方脚本都会直接拿到令牌。这与"局域网自用 + 无第三方依赖"的前提绑定，若引入 CDN 资源需重新评估。
2. **编辑弹层无 MAC/广播地址的预校验格式提示**，非法值提交后依赖服务端 400 的 `message` 回显（文案已可读）。前端不重复实现一套校验规则，避免两处规则漂移。
3. **"恢复后可继续操作"的断言依赖提示条自动隐藏**，若未来把错误横幅改为不自动消失，该断言需同步调整（脚本在 `tmp/`，不入库）。
4. **多设备同时校验共用一个 5 秒轮询定时器**，客户端上限 130 秒；若后端将来把 120 秒上限改为可配置，此处常量需联动（已在契约中注明）。
